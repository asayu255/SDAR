# 符号一致重み付け(target モード)— step 150 A/B 結果の記録と分析

記録日: 2026-08-15 / アーム: `sdar_multitask_opd_grpo_signweight_target_qwen3_1.7b`
対照: 1本目実験の OPD+GRPO アーム(`sign_weight.*` 以外は同一設定、ロックテストで機械検証済み)。
評価プロトコル: val_per_task_batch_size 126、alfworld/webshop T=0.4 サンプリング、search greedy。
報告値の分数一致(96/126=0.762, 87/126=0.690, 82/126=0.651)から N=126 を確認済み。

N=126 の2群差95%検出限界(≈0.107〜0.12)のちょうど上に乗っている。合算では p≈0.04。

## パターンとしての証拠(単独 z より強い部分)

1. **事前予測の的中(負の対照)。**「Search は動かない」は
   `docs/multitask_mechanism_v2_proposal.md` §3.5 に**走行前(8/10)にコミット済み**の予測。
   実測 −0.001。動くと予測した2タスク(界面・プロンプトを実装レベルで共有)だけが動いた。
2. **6アーム包絡の外。**1本目5アーム@150 の範囲は AlfWorld 0.540–0.683 /
   WebShop Score 0.760–0.785 / Acc 0.611–0.659。重み付けアームは3指標すべてで
   包絡上端を超える(+0.079 / +0.030 / +0.031)。目的関数が大きく異なる5アームの
   ばらつき幅を超えており、「アーム間ノイズの範囲内」では説明しにくい。
   (ただし包絡最大値との比較は選択バイアスを含むため記述統計に留める。)
3. **サンプル効率。**AlfWorld 0.762@150 は対照の 300step 値 0.754 を既に超える
   (半分のステップで対照の到達点)。WebShop は未達(score 0.869 / Acc 0.738@300)。
4. **教師超えマージンの拡大。**WebShop Acc の教師超えは対照でも +0.048 あったが
   +0.103 に拡大。AlfWorld は対照が教師未満(−0.016)だったのが +0.095 に。
   target モードは固定点を教師から動かす唯一の変種であり、教師超えの拡大は機構の
   予測方向と整合する。

## まだ言えないこと(誠実性のための列挙)

- **帰属は未確定。**利得が「教師間符号情報」によるのか「教師分布への摂動一般
  (label smoothing 的正則化)」によるのかは、符号シャッフル対照(同じ重み分布を
  ランダム割当)か position モードを走らせるまで分離できない。
  Search の不動は摂動一般説への部分的反証だが、Search は飽和気味(ATOD の外部傍証)
  なので決定打ではない。
- **シード1本。**デコード分散(T=0.4)も1回分。再評価×3が最安の頑健化。
- **300step での残存は未知。**1本目の転移は 150→300 で消えた。同じ消え方をするか、
  target モードの固定点移動が残るかが、次の決定的観測。
- **完遂規律への集中は弱い。**SR/score 比 0.836 → 0.847(+0.011)。利得は
  score と Acc に比例的で、v2 提案 §3.5 の予測1(空白ゲート付き K′ 用)を
  この簡易版が再現しているとは言えない。
- 対照の数値は1本目実験時の評価。同一プロトコルだが同時再評価ではない
  (GPU 数 3→2 の差もあり — 配置のみで目的関数は不変)。

## 次のアクション(優先順)

1. **両チェックポイントの validation を各3回**(評価シード違い、インスタンスログ保存)。
   数時間で「デコード運」仮説を潰し、McNemar ペア化(同一126インスタンス)で検出力を上げる。
2. **300step まで継続**(save_freq を戻して再開)。転移消失パターンの再現/非再現が
   本アームの主張の核を決める。
3. **符号シャッフル対照**(帰属)。position モードより優先 — 摂動一般説を直接殺せるのは
   こちら。150step 1本 ≈ 35–37h。
4. 次回実装に持ち越し済みの計測: タスク別 sign_weight frac、素の教師分布に対する KL の並記、
   off-task 中立の内訳(割れ vs 沈黙)。
