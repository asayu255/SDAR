対照: 1本目実験の OPD+GRPO アーム(`sign_weight.*` 以外は同一設定、ロックテストで機械検証済み)。

## パターンとしての証拠(単独 z より強い部分)

1. **事前予測の的中(負の対照)。**「Search は動かない」は
   `docs/multitask_mechanism_v2_proposal.md` §3.5 に**走行前(8/10)にコミット済み**の予測。
   実測 −0.001。動くと予測した2タスク(界面・プロンプトを実装レベルで共有)だけが動いた。
2. **6アーム包絡の外。**1本目5アーム@150 の範囲は AlfWorld 0.540–0.683 /
   WebShop Score 0.760–0.785 / Acc 0.611–0.659。重み付けアームは3指標すべてで
   包絡上端を超える(+0.079 / +0.030 / +0.031)。目的関数が大きく異なる5アームの
   ばらつき幅を超えており、「アーム間ノイズの範囲内」では説明しにくい。
   (ただし包絡最大値との比較は選択バイアスを含むため記述統計に留める。)
3. **サンプル効率。**AlfWorld 0.762@150 は対照の 300step 値 0.754 を既に超える
   (半分のステップで対照の到達点)。WebShop は未達(score 0.869 / Acc 0.738@300)。
4. **教師超えマージンの拡大。**WebShop Acc の教師超えは対照でも +0.048 あったが
   +0.103 に拡大。AlfWorld は対照が教師未満(−0.016)だったのが +0.095 に。
   target モードは固定点を教師から動かす唯一の変種であり、教師超えの拡大は機構の
   予測方向と整合する。

## 検討して棄却した交絡: 「再正規化そのものが効いたのでは」

target モードは `reweight_teacher_logprobs` の中で再正規化を行う。元の OPD には
無かった処理なので、利得が符号情報ではなく再正規化に帰属する可能性を検討した。

**棄却の根拠1(厳密)。**tail(top-k 外の質量)を別枠で保持しているため、
w≡1 のとき $Z = \sum_v p_t(v) + \text{tail} = 1$ となり、関数は**厳密な恒等写像**になる
(数値確認済み: max|out−in| = 0.000e+00)。Revisiting OPD 方式の
「top-k 内で再正規化して推定量を変える」には**なっていない**。重みが一様なら
何も起きない以上、再正規化は独立した介入たりえない。
テストで固定: `test_target_shift_is_exactly_zero_when_nothing_is_flagged`。

**棄却の根拠2(より厄介な変種)。**「重み付けが目標分布を系統的に鋭く/平坦にした
=温度変更だったのでは」という交絡。step151 実測の状態比率で、重みと候補順位の相関を
3通り(無相関/高確率ほど増強/その逆)に振って測定した結果、
エントロピー変化は −0.003〜−0.005 nats、**等価温度 T≈0.998**。温度換算 0.2% であり、
AlfWorld +0.111 を説明できる量ではない。

**重要な副次的帰結。**この交絡が小さいことが、符号シャッフル対照の解釈を可能にする。
シャッフルは符号情報と系統的シャープ化の**両方**を同時に壊すので、もしシャープ化が
効いていたなら「シャッフルで利得消失」は符号情報の証拠にならなかった。
T≈0.998 が確認できているので、シャッフル対照は符号情報を特異的に検定できる。

**次回走行では実測する。**`sign_weight/target_kl`(= KL(教師‖書換後目標)、
`actor/teacher_kl_loss` と同単位なので比が読める)と
`sign_weight/target_entropy_delta` をステップ毎に記録するよう実装済み。
上記はシミュレーションによる推定なので、実測値で置き換えること。

なお参考として、シミュレーション上の目標移動量は 0.004〜0.008 nats。
step151 の `actor/teacher_kl_loss = 0.222` に対して **2〜4%** にあたる。
「わずか数%の移動が +0.111 を生んだ」は、150step × 数百万トークンにわたる
一貫方向のバイアス蓄積として説明可能だが、同時に「その程度で動くなら中身ではなく
摂動の存在自体では」という反論も呼ぶ。シャッフル対照の優先度を上げる根拠。

## まだ言えないこと(誠実性のための列挙)

- **帰属は未確定。**利得が「教師間符号情報」によるのか「教師分布への摂動一般
  (label smoothing 的正則化)」によるのかは、符号シャッフル対照(同じ重み分布を
  ランダム割当)か position モードを走らせるまで分離できない。
  Search の不動は摂動一般説への部分的反証だが、Search は飽和気味(ATOD の外部傍証)
  なので決定打ではない。
- **シード1本。**デコード分散(T=0.4)も1回分。再評価×3が最安の頑健化。
- **300step での残存は未知。**1本目の転移は 150→300 で消えた。同じ消え方をするか、
  target モードの固定点移動が残るかが、次の決定的観測。
- **完遂規律への集中は弱い。**SR/score 比 0.836 → 0.847(+0.011)。利得は
  score と Acc に比例的で、v2 提案 §3.5 の予測1(空白ゲート付き K′ 用)を
  この簡易版が再現しているとは言えない。
- 対照の数値は1本目実験時の評価。同一プロトコルだが同時再評価ではない
  (GPU 数 3→2 の差もあり — 配置のみで目的関数は不変)。

## 300step の解釈: 何が支持され、何がされないか

**支持される: サンプル効率としての転移増強。**150step で開いた差が 300step で
50%(AlfWorld)/ 115%(Acc)/ 156%(Score)縮小した。両アームが共通の到達点へ
収束する形であり、1本目で観測された「転移は150stepで大きく300stepで消える」
パターンの再現である。理論(§5: 最適解に転移は存在しない)の予測とも一致する。

**支持されない: 到達点の押し上げ。**target モードは OPD 項の固定点を動かすが、
その OPD 項は損失全体の 3〜6% でしかない(`teacher_kl_loss_weighted × 0.01`
対 `pg_loss_weighted × 1.0`)。合成された最適解は GRPO が支配し、その最適解は
報酬最大化方策であって重み付けの影響を受けない。**固定点を動かす設計であっても、
動かした先が支配的でなければ到達点は変わらない** — これが観測と整合する説明である。

**要注意: WebShop の反転。**単独では有意でない(Acc z=−0.14)が、
Score/Acc の両方が同方向に負であり、単なるノイズと断じるには弱い。
対抗する読みが2つある。

1. 収束の行き過ぎ(初期値が高かった分だけ余地が少なく、たまたま下回った)
2. 後半で蒸留項が GRPO と綱引きし、重み付けが有害化した

区別する材料: 対照の 150→300 の伸びは3指標とも +0.10 前後で揃うのに対し、
重み付けアームは +0.048 / +0.040 / +0.023 と一貫して小さい。
「高い所から始めたので伸びしろが少ない」で説明できる範囲かどうかは、
**中間ステップ(200, 250)の評価**で決まる。単調に縮むなら 1、
どこかで頭打ち・下降に転じるなら 2。チェックポイントは `save_freq=25` で
残っているので追加学習なしで測れる。**最も安い決定的観測。**

## 「300step の上昇は GRPO によるもの」という主張について

方向としては1本目のデータに支持される(純OPD は Alfworld 0.683@150 → 0.611@300
と実際に劣化しており、蒸留信号は150step で頭打ち)。ただし論文に書く際は
**主張が一段強すぎる**点に注意。

- 「上昇量はほぼ GRPO」なら、150step で得た差は**そのまま持ち越されるはず**で、
  縮小・反転は説明されない。実際に必要な主張は
  「蒸留信号は 150step で飽和し、**かつ**両アームが共通の GRPO 最適解へ収束するので、
  蒸留側で作った差は後半で吸収される」である。
- この主張は §5 の理論(3タスク同時の最適解は routed OPD で、そこに転移は無い)
  から演繹でき、1本目の5アーム全体の 150→300 挙動とも整合する。
  **理論からの予測が2本の独立な実験で当たった**という形にできる。

4. **WebShop は本質的に不安定。**帯ごとに符号が反転する(+0.024 / −0.032 / +0.052 / +0.010)。

   「後半で有害化した」の証拠にはならない可能性が高い。
