# OPD 係数の機構に残る 3 つの問題: 信頼と波及の分離

状態: **検討のみ。走行中の redistribute アームには触れない。** 対象は
[opd_coefficient_arm_design.md](../../cross-teacher-target-6b2123/docs/opd_coefficient_arm_design.md)
（`claude/opd-per-task-coef`）の機構。数値は `~/grad_probe/terms_n8_fixed.json`（step 300、$N=8$）から再計算した。

問い（ユーザー提起）:

1. 同一タスクの RL–OPD cosine（対角）を、他タスク間の cosine（非対角）と同じ扱いにしている。対角は重視すべきではないか。
   対角が負なら「RL が教師を超えた」可能性があるが、非対角の負はそれを意味しない。
2. RL–RL の勾配衝突もある。ただし OPD 側の後でよい。
3. 重み付けの理論的根拠が足りない。

---

## 0. 結論

1. **対角と非対角は別の問いに答える量で、同じ和に入れるべきではない。指摘は正しい。**
   対角 $C_{jj}=\langle r_j,d_j\rangle$ は**信頼**（教師 $j$ はタスク $j$ にまだ有用か）、
   非対角 $C_{ij}$ は**波及**（教師 $j$ の引きが、共有パラメータを通じてタスク $i$ の報酬を害するか）。
   現行の $c_j=\sum_i \tilde C_{ij}$ はこの 2 つを等しい票で足している（§1）。
2. **ただし対角の符号は信頼を測れない。** $C_{jj}<0$ には「生徒が教師を超えた」「事前分布が雑音のある報酬に抵抗している」
   「停留点近傍の張力」の 3 つの読みがあり、勾配だけでは区別できない（§2、命題）。
   信頼の正しい証拠は**報酬水準**（タスク $j$ の生徒 vs 教師）か教師の誤差分散（第 2 シード）であって、勾配の符号ではない。
   alfworld は生徒 0.754 < 教師 0.849 で超えていない。**webshop と search の教師の検証値はこのホストに無い**（§2.3）。
3. **波及に対してスカラー $b_j$ は鈍い道具である。** 最強の波及 $\cos(r_{\rm alf},d_{\rm web})=-0.106$ の対立成分は
   $d_{\rm web}$ のエネルギーの **1.1%**。$b_{\rm web}$ を半減する介入はその **約 45 倍**。
   したがって**走行中のアームの実体は「webshop の $\beta$ を半減、search の $\beta$ を ×1.19」であり、
   $C$ は「どのタスクか」を選んだだけ**である。効果が出ても干渉除去の証拠にはならず、
   webshop の固定点（$\tau$）を動かした効果として読む（§3）。
4. **RL–RL は後回しで正しい。** step 300 で cosine 0.002〜0.016、符号は混在（§4）。
5. **現行の規則は「OPD による RL 損失の一次減少の最大化 + 線形予算 + 近接罰則」の解であり、導出はあるが前提が 2 つ届いていない**（§5）。
   整合する形は $b_j = t_j\cdot s_j$: $t_j$ は報酬証拠からの信頼、$s_j$ は非対角からの波及補正。
   波及をより整合的に扱うなら、それはスカラーではなく $d_j$ の**射影**である（§3.2）。ただし測定上その成分は 1% なので、
   射影版を走らせる価値は事前に低いと言える。

## 1. 対角と非対角は別の量である

損失 $L(\theta;b)=\sum_i L_i^{RL}(\theta)+\sum_j b_j D_j(\theta)$。$r_i=\nabla L_i^{RL}$ はタスク $i$ の状態上、
$d_j=\nabla D_j$ はタスク $j$ の状態上で計算される。

| | 計算される状態 | 答える問い | 機構上の位置 |
|---|---|---|---|
| 対角 $C_{jj}=\langle r_j,d_j\rangle$ | 同じ（タスク $j$） | 報酬の押しと教師の引きが**同じ状態で**揃っているか | 命題 2: $b_j$ はタスク $j$ の全位置で $\tau$ を動かし、**タスク $j$ の固定点**を決める。一次 |
| 非対角 $C_{ij}$, $i\ne j$ | 違う | 教師 $j$ に寄ることが、共有パラメータ経由でタスク $i$ の報酬を動かすか | タスク $i$ の固定点は $b_j$ に依らない。効くのは経路（動学）だけ。二次 |

タスク $j$ 自身の結果にとって対角が一次、非対角が二次という点で「対角を重視すべき」は正しい。
現行規則が等しい票にしたのは、目的関数を**全タスクの RL 損失の和**に取ったからで（§5）、
その目的関数の下では各テーブルの要素は区別されない。目的関数の選択が答えを決めている。

step 300 のデータで分けると:

| | alfworld | search | webshop |
|---|---:|---:|---:|
| 対角 $\tilde C_{jj}$（cosine） | −0.003（$t$ −0.1、負 5/8） | −0.022（$t$ −0.9、負 4/8） | **−0.097**（$t$ −1.5、負 5/8） |
| 非対角の列和 $\sum_{i\ne j}\tilde C_{ij}$ | −0.016 | +0.047 | **−0.147**（alf −0.106、search −0.040） |
| $b$（対角込み、走行中） | 1.076 | 1.191 | 0.500 |
| $b$（非対角のみ） | 0.993 | 1.234 | 0.500 |

webshop はどちらの量でも最も負で、順位は変わらない。差は alfworld の 1.076 → 0.993 だけである。
**走行中のアームの内容（webshop 半減、search 増）は、対角の扱いに依らない。** 変わるのは解釈（§3）と alfworld の係数。

## 2. 対角の符号は信頼を測れない

### 2.1 命題（3 つの読みは勾配だけでは区別できない）

タスク $j$ の状態上で、報酬の勾配 $r_j$ と教師への勾配 $d_j$ を考える。

(a) **生徒が教師を超えた**: $J_j(\pi_\theta) > J_j(\pi_j)$。教師の引きは平均して報酬を下げる向きなので $C_{jj}<0$ は必要条件。

(b) **事前分布が雑音に抵抗している**: 報酬の標本勾配 $r_j$ が雑音・報酬ハックを含み、教師がそれに逆らっている。
このとき $C_{jj}<0$ だが、教師は有用である。$r_j$ の期待値と標本の違いは 1 点の勾配では見えない。

(c) **停留点近傍の張力**: $L_j^{RL}+b_jD_j$ の停留点では $r_j=-b_jd_j$（交差項を除く）なので $\cos=-1$。
教師が有用でも無用でも、束縛が効いていれば負になる。

(a)(b)(c) はすべて $C_{jj}<0$ を与え、$C_{jj}$ の値も符号も 3 つを分けない。$\square$

step 300 では $\|r_j\|/\|d_j\|$ が 9.1 / 11.0 / 5.8 で、タスクごとのバランスは停留点から遠い（(c) ではない）。
残るのは (a) か (b) で、これは**報酬水準**でしか分けられない。

### 2.2 信頼の正しい証拠

理論文書 §3.4: KL 正則化 RL を近似 Bayes 推論として読むと、$\tau_j$ は事前分布（教師）の精度に比例すべきで、
精度は教師の誤差分散 $\sigma^2_{\varepsilon,j}$ で決まる。これを測る手段は 2 つ。

* **報酬水準**: $J_j(\text{生徒}) \ge J_j(\text{教師})$ なら教師は超えられており、$\tau_j$ を落とす根拠になる。教師と独立な証拠で、検証 1 回で測れる。
* **第 2 シード**（理論文書 E4）: $\sigma^2_{\varepsilon,j}$ の直接測定。

どちらも勾配の符号ではない。**「対角が負 = 超えた」は (a) の必要条件を十分条件と読んでいる。**

### 2.3 今わかっていること

| タスク | 生徒（control @300） | 教師（単タスク @300） | 超えたか |
|---|---:|---:|---|
| alfworld | 0.754 | **0.849** | いいえ（−9.5pp） |
| webshop acc | 0.738 | **未測定**（このホストに記録なし） | 不明 |
| search | 0.395 | **未測定** | 不明 |

alfworld の対角 ≈ 0 は「超えていない」と整合する。webshop の対角 −0.097 が (a) か (b) かは、
**webshop 教師の検証値 1 回（約 38 分）で決まる**。走行中のアームは $b_{\rm web}=0.5$ を「波及」で正当化しているが（§3）、
実体は信頼の切り下げなので、この 1 回の測定が結果の解釈を左右する。

## 3. 波及に対してスカラー係数は鈍い

### 3.1 エネルギーで見る

$\cos(r_i,d_j)=c$ のとき、$d_j$ のうち $\hat r_i$ 方向の成分は $|c|\,\|d_j\|$、エネルギーは $c^2\|d_j\|^2$。

| 波及の対 | cosine | 対立成分のエネルギー割合 $c^2$ |
|---|---:|---:|
| alfworld:RL ← webshop:OPD | −0.106 | **1.1%** |
| search:RL ← webshop:OPD | −0.040 | 0.16% |
| webshop 列の合計 | | **1.3%** |

$b_{\rm web}=0.5$ は $d_{\rm web}$ を 50% 落とす。波及として測られたものは 1.3%。**介入は動機の約 40〜45 倍**である。
半減が取り除く波及は 1.3% の半分（0.65%）で、失う蒸留は 50%。

**帰結**: 走行中のアームが control と差を出しても、それは干渉を除いたからではない。webshop の教師への信頼 $\tau$ を半分にした
（＝ webshop の固定点を報酬側へ寄せた）効果として読むのが、測定と整合する唯一の読みである。
一様アーム（×1.11）もこの 2 つを分けない。

### 3.2 整合する操作は射影であり、それは 1% を動かす

波及だけを除く操作は $d_j \leftarrow d_j - \sum_{i\ne j}\max(0,-\langle d_j,\hat r_i\rangle)\,\hat r_i$
（PCGrad 型、ただし **OPD 勾配だけ**に掛ける。RL 項は理論文書 §5.4 のとおり触らない）。
これは対立成分を全部除き（波及 −100%）、$d_j$ のエネルギーを 1.3% 失う。スカラー半減（波及 −50%、蒸留 −50%）
と比べて、限界効率は約 90 倍。

しかし (i) 毎 step タスク別 RL 勾配が要る（backward 6 倍）、(ii) $N=1$ の $r_i$ は雑音が大きく射影方向が揺れる、
(iii) **除けるのは 1.3% のエネルギーで、測定上その効果は小さい**。
射影版は「理論的に正しい波及の扱い」だが、この教師集合で走らせる価値は事前に低い。
**波及は、このデータでは係数を動かす理由にならない。** 係数を動かす理由があるとすれば信頼（§2）である。

## 5. 現行規則の導出と、届いていない前提

現行の $b_j=\mathrm{clip}(1+\kappa(c_j-\bar c_q))$ は次の問題の解である:

$$
\max_b\ \sum_j b_j c_j\ -\ \tfrac{1}{2\kappa}\|b-\mathbf 1\|^2
\quad\text{s.t.}\quad \sum_j q_jb_j=1,\ b\in[b_{\min},b_{\max}]
$$

第 1 項は SGD 1 step で OPD がもたらす $\sum_i L_i^{RL}$ の一次減少（$P=I$、cosine 正規化）。導出は成り立つ。届いていない前提:

1. **目的関数が OPD を「RL 損失を一次で下げる手段」としてしか評価しない。** 事前分布としての役割・固定点への効果（命題 2）に
   価値を置かないので、制約が無ければ $b\to0$ に向かう。予算 $\sum q_jb_j=1$ はそれを止めるために**外から**置いたもので、導出されていない。
2. **対角と非対角を同じ係数で足す**のは目的関数を全タスクの和に取った帰結で、§1 のとおり 2 つは別の問いに答える。
3. box と近接罰則は選択。

これらは pilot として許容できるが、「理論的に整合した重み」ではない。ユーザーの感覚は正しい。

### 5.1 整合する形

$$
b_j = t_j \cdot s_j
$$

* **信頼 $t_j\in[t_{\min},1]$**: 教師と独立な証拠から。第一候補は報酬水準 $J_j(\text{生徒})/J_j(\text{教師})$ の関数
  （超えるまで 1、超えた後は減衰）。これは per-task の $\beta(t)$ 減衰を報酬で駆動する形で、理論文書 §5.3(a) の per-task 版。
  第 2 シードが取れれば $t_j\propto 1/\sigma^2_{\varepsilon,j}$。**対角 $C_{jj}$ は使わない**（§2）。
* **波及 $s_j$**: 非対角のみから、予算付きで $s_j=\mathrm{clip}(1+\kappa(c^{\rm off}_j-\bar c^{\rm off}_q))$。
  ただし §3 のとおり測定上 1% なので、この因子はほぼ 1 のままでよい。整合的に扱うなら射影。

今のデータでは: $t=(1,\,?,\,?)$（webshop / search の教師値待ち）、$s=(0.993,\,1.234,\,0.500)$。
$s$ の webshop 0.5 は box 境界の帰結で、波及 1.3% が要求する量ではない。**波及だけなら $s_{\rm web}$ は 1 に近い値でよく、
0.5 は信頼の切り下げとしてしか正当化できない。** 走行中のアームはこの意味で「信頼アーム」である。

## 6. 走行中の run への含意（触らない）

* 止める理由は無い。$b=(1.076,1.191,0.5)$ は「webshop の $\beta$ 半減・search ×1.19」の per-task $\beta$ 実験として有効。
* **読み方を変える。** 差が出れば「webshop の固定点を報酬側へ寄せた効果」。差が出なければ「この強度の信頼変更は効かない」。
  干渉除去については、どちらの結果からも何も言えない（除いた干渉が 0.65% しかない）。
* 一様アームは合成ノルムの対照としては有効だが、信頼と波及を分ける役には立たない。
