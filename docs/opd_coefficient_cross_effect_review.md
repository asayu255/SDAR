# OPD 係数を RL–OPD 交差効果で調整する提案の妥当性

状態: **検討のみ。実装なし。** 提案本文は会話で与えられたもの（以下「提案」）。
検証データは `~/grad_probe/terms_n8_fixed.json`（[cross_teacher_theory.md](cross_teacher_theory.md) §4.14、
OPD+GRPO control step 300、$N=8$ バッチ、取得修正後）。これは RL 項を持つ唯一の有効な勾配測定である。
再構成と QP の再現は `scripts/opd_cross_effect_qp.py`（引数なしで同じ JSON を読む）。

提案の要点: 係数込みの RL 勾配 $r_i$、OPD 勾配 $d_j$ に対し $C_{ij} = r_i^\top P d_j$ を測り、
$\min_{0\le b\le 1}\|b-\mathbf 1\|^2$ s.t. $C_i b \ge 0\ (i\in S)$ で 3 つの OPD 係数 $b_j$ を決める。
$N=8$ 平均内積・$P=I$・$S$ = 全 3 タスクで解は $b=(0,0,0)$ だった。

---

## 0. 結論

1. **定式化は整合的だが、係数を決める根拠にはならない。** 一次近似 $\Delta L_i^{RL} \approx -\eta\sum_j C_{ij} b_j$ は
   SGD・$P=I$ で正しく、信頼を教師と独立な信号（報酬勾配）で決める点は理論文書 §5.1 の原則 2 に合う。
   問題は「この一次量が OPD の価値を測っているか」（§4）と「推定できているか」（§3）で、前者は構造的、後者は統計的。
2. **$b=(0,0,0)$ は search の RL 行 1 本で決まっている**（§3.1）。$S=\{\text{search}\}$ だけでも解は 0、
   $S=\{\text{alfworld},\text{webshop}\}$ なら $b^*=(1,\,1,\,0.39)$。search 行の 3 成分の $p$ 値は 0.34 / 0.87 / 0.04 で、
   search の RL 勾配は 8 バッチで生存群 1〜5 / 15 の推定である。**提案自身の $S$ の選定規則（RL 信号が信頼できるタスク）を
   適用すると search は $S$ に入らず、全停止は消える。** 全停止は「厳密制約版の限界」ではなく $S$ の選び方の帰結。
3. **$S$ を正しく選んでも解は安定しない**（§3.2）。bootstrap で $b_{\text{web}}=0$ が 21%、平均内積を cosine に替えると
   $b_{\text{web}}$ は 0.39 → 0.075、中央値なら 0.005。9 成分のうち Bonferroni 後に有意なものは無い。
4. **構造的問題 (a): 制約 $C_i b\ge 0$ は、正則化項がデータ項の損失を一次で上げないことを要求している**（§4.1）。
   結合目的関数の停留点では任意の正定値 $P$ で $\sum_{ij}C_{ij} = -(\sum_i r_i)^\top P(\sum_i r_i) \le 0$ が成り立つので、
   OPD が効いている限り $b=\mathbf 1$ は実行不能で、QP は必ず縮める。「現行係数で条件を満たせば変更しない」は
   OPD が不活性のときにしか起きない。データでも $\langle\sum r,\sum d\rangle$ は 8 バッチ中 7 で負。
   **実質は $\beta(t)$ 減衰（理論文書 E1）を、雑音の多いトリガーで再発明している。**
5. **構造的問題 (b): 一次の交差効果は OPD の主効果を測らない**（§4.2）。OPD が成功率に効く経路は固定点（命題 2 の $\tau$）と
   初期の到達速度（§4.3）であり、どちらも $C$ には現れない。OPD の一次寄与は RL 自身の 0.3〜1%（上限でも数 %）で、
   $b$ を動かして一次で変わるのはこの範囲だけ。$\beta=0.01$ で $A\ne 0$ の位置が既に報酬支配なら、step 300 以降の
   短区間で $b$ を動かしても alfworld / webshop は control と区別できず、search（OPD が唯一の勾配である位置が大半）だけが
   負に動きうる、が理論からの事前予測。
6. **$P=I$ は選択ではなく制約だった**（§4.4）。測定に使った checkpoint は HF マージで Adam 状態を失っている。
   前処理係数は 1 ユニット内で 45〜2000 倍動く（理論文書 §4.7.2）ので $r^\top Pd$ の符号が $r^\top d$ と一致する保証はない。
   Adam 状態付きの OPD+GRPO checkpoint は 8/13 アーム（`verl_agent_opd_grpo_tmp_multitask`、world size 2、
   `optim_*.pt` 6.9 GB/rank）にあるが、それは target アームで control ではない。
7. **測定に残る信号は 1 つ**（§5）: webshop-OPD 列が 3 行とも負（$t=-2.8/-2.5/-1.75$）。理論文書 §4.14.3
   （search↔webshop の OPD が 8/8 で負）と §3.6（alfworld ← webshop が出力空間で唯一再現する負）と同じ向きで、
   3 つの独立な測定が「webshop 教師が他タスクと食い違う」を指している。ただし多重比較後は非有意。
   これは係数の最適化問題ではなく**診断**として価値がある。試すなら自由度は $b_{\text{web}}$ の 1 つで、QP は要らない。

## 1. 提案の定式化で正しい部分

* $\theta \leftarrow \theta - \eta\,g(b)$ に対し $\Delta L_i^{RL} \approx r_i^\top\Delta\theta = -\eta\big(\sum_k r_i^\top r_k + \sum_j b_j\, r_i^\top d_j\big)$。
  OPD の寄与は $-\eta\sum_j C_{ij}b_j$ で、提案の符号の読み（$C_{ij}>0$ なら $j$ の OPD が $i$ の RL 損失を下げる）は正しい。
* PPO surrogate の勾配は $r=1$ で $-\nabla J_i$ なので、「RL 損失を下げる」は「期待収益を一次で上げる」と同義（理論文書 命題 2 の証明）。
* 報酬勾配は教師と独立な信号なので、信頼をこれで決めることは理論文書 §5.1 の原則 2（教師統計で信頼を決めない）に反しない。
  cross-teacher の識別不能性（§3.2）にも触れない。
* 「負のペアを個別に切らず、正の寄与との合計で判断する」は、パラメータが共有されている以上、正しい集計単位である。
* 3 アーム（固定 / 同じ平均係数の一律減衰 / タスク別）の対照は、「OPD 量を減らした効果」と「交差効果を使う追加価値」を
  分離する正しい設計である。

## 3. QP の再現と、$b=0$ の由来

### 3.1 $b=(0,0,0)$ は search 行だけの帰結

| $S$ | $b^*$ | 縛っている制約 |
|---|---|---|
| 全 3 タスク | **(0, 0, 0)** | search 行 |
| {search} のみ | (0, 0, 0) | search 行 |
| {alfworld, webshop} | **(1, 1, 0.39)** | webshop 行（$0.040 - 0.101\,b_{\text{web}} \ge 0$） |
| {alfworld} のみ | (1, 1, 0.74) | alfworld 行（$0.142 - 0.191\,b_{\text{web}} \ge 0$） |
| {webshop} のみ | (1, 1, 0.39) | webshop 行 |

search 行は 3 成分すべてが負（−0.058, −0.037, −0.154）なので、$b\ge 0$ の下で $C_{\text{search}}\,b\ge 0$ を満たす $b$ は 0 しかない。
つまり全停止は、$p$ 値 0.34 と 0.87 の 2 成分の**符号**に懸かっている。search の RL 勾配は 8 バッチで生存群が 1〜5 / 15
（理論文書 §4.9.4 の退化）で、ノルムも 5.4〜16.8 と 3 倍動く。提案は $S$ を「RL 信号と交差効果の推定が十分に信頼できるタスク」と
定義しているので、この規則を適用すれば search は $S$ に入らない。**厳密制約版の解は $(0,0,0)$ ではなく $(1,1,0.39)$ であり、
全停止は $S$ の誤選択の産物である。**

### 3.2 $S$ を正しく選んでも解は決まらない

| 摂動 | $S$ = 全 3 | $S$ = {alf, web} |
|---|---|---|
| 平均内積（提案） | (0, 0, 0) | (1, 1, 0.39) |
| 平均 cosine | (0, 0, 0) | (0.91, 1, **0.075**) |
| 中央値 | (0.005, 1, 0) | (0.89, 1, **0.005**) |
| $\lvert t\rvert>2$ の成分だけ | (1, 1, 0) | — |
| bootstrap（8 バッチ再抽出 ×400） | $P(\text{全部 }0)=0.61$、平均 (0.28, 0.38, 0.10) | $P(b_{\text{web}}=0)=0.21$、平均 (0.75, 0.82, 0.28) |
| 1 バッチ抜き（8 通り） | 5 通りで 0、3 通りで $b_{\text{alf}}\in[0.39,0.76]$ | — |
| 単一バッチ | 6 通りで 0、b4 で (1, 0, 0)、b5 で (1, 1, 0.56) | — |

**統計量の選択（内積 / cosine / 中央値）だけで $b_{\text{web}}$ は 0.005〜0.39 を動き、8 バッチの再抽出で全停止と部分減衰が
6:4 で入れ替わる。** 平均内積は $\|r_i\|\|d_j\|$ でバッチを重み付けるので、search のノルムが 16.8 の b5 が search 行を支配する
（b5 を落とすと S=全 3 でも 0 のまま、b5 単独では $(1,1,0.56)$）。

硬い制約を点推定に掛ける形は、この雑音水準では「どれかの行がたまたま全成分負になれば全停止」という構造を持つ。
$S$ を絞っても、残る行の符号が揺れる限り解は揺れる。

## 4. 理論的検討

### 4.1 命題: 停留点では $\sum_{ij}C_{ij}\le 0$（制約は構造的に破れる）

$b=\mathbf 1$ の結合目的関数 $L=\sum_i L_i^{RL}+\sum_j D_j$（係数は $r, d$ に吸収）の停留点 $\theta^*$ では
$\sum_i r_i + \sum_j d_j = 0$。任意の対称正定値 $P$ について

$$
\sum_{i,j} C_{ij} = \Big(\sum_i r_i\Big)^{\!\top} P \Big(\sum_j d_j\Big) = -\Big(\sum_i r_i\Big)^{\!\top} P\Big(\sum_i r_i\Big) \le 0,
$$

等号は $\sum_i r_i = 0$、すなわち OPD 項が不活性（教師制約が効いていない）のときに限る。∎

帰結:

* 停留点の近傍では $\sum_i C_i\mathbf 1 < 0$ なので少なくとも 1 行で $C_i\mathbf 1<0$、**$b=\mathbf 1$ は実行不能**。
  提案の「現行係数で条件を満たせば変更しない」は、OPD が何もしていないときにしか成り立たない。
* 停留点でなくても、正則化項の勾配は「データ項が行きたい方向に逆らう」成分を持つのが正則化の定義であり、
  $\langle\sum r, \sum d\rangle<0$ は学習が進むほど確実になる。データ（step 300）で 8 バッチ中 7 が負、行和は 3 タスクとも負。
* したがって QP は**学習が進むほど $b$ を縮める**。これは理論文書 §5.3(a) の $\beta(t)$ 減衰（E1）と同じ作用で、
  違いは減衰の時期とタスク配分を雑音の多い $C$ に委ねることだけである。

GRPO については $r_i$ は標本勾配で、停留点で消えるのは期待値 $\mathbb E[r_i]$ である。交差タスク対は別の行から計算されるので
$\mathbb E[C_{ij}]=\mathbb E[r_i]^\top P\,\mathbb E[d_j]$ で上の命題がそのまま効く。同一タスク対は同じ行を共有するので
$\mathrm{Cov}(r_i,d_i)$ が混入し、$C_{ii}$ は期待値の積ではない（§4.3）。

### 4.2 一次の交差効果は OPD の主効果を測らない

理論文書 命題 2 により、OPD+PG の各位置の固定点と更新方向は比 $\tau(x)=\beta W^{kl}/W^{pg}$ が決める。$b_j$ を下げることは
タスク $j$ の全位置で $\tau$ を下げること、すなわち**固定点を報酬単独の側へ動かす**ことである。これが OPD の主効果であり、
一次の $C_{ij}$ には現れない。

もう一つの主効果は初期動学である（§4.3: signweight target アームの優位は step 31–60 で立ち、200 以降で消える）。
step 300 の $C$ はこの時期の情報を持たない。

大きさで言うと、OPD の一次寄与 $-\sum_j C_{ij}$ は RL 自身の一次項 $R_{ii}=\|r_i\|^2$ の 0.25〜1%（$R_{ii}$ は雑音を含むので
これは下限側だが、ノルム比 4〜16 と $|\cos|\le 0.1$ から上限でも数 %）。$b$ を $[0,1]$ で動かして一次で変わるのはこの量であり、
成功率に届く経路は固定点の移動しかない。

$\beta=0.01$ では $A\ne 0$ の位置の固定点は既に報酬支配（理論文書 §4.5）なので、事前予測はこうなる:

| タスク | step 300 以降の短区間で $b_j<1$ にしたときの予測 |
|---|---|
| alfworld / webshop | 固定点はほぼ動かない。control・一律減衰・タスク別の 3 アームは区別できない（反復雑音 alfworld SD 1.39pp） |
| search | 生存群 1〜5 / 15、$A=0$ の位置では OPD が唯一の勾配。$b_{\text{search}}$ を下げれば信号を消す側にしか働かない |

QP が $S$ = 全 3 で出した「$b_{\text{search}}=0$」は、**最も雑音の多い行を根拠に、OPD が唯一の信号であるタスクの OPD を切る**
という、想定しうる最悪の配分である。

### 4.3 同一タスク対には共分散が混入する

$r_i$ と $d_i$ は同じ軌跡から計算されるので、$\mathbb E[r_i^\top d_i] = \mathbb E[r_i]^\top\mathbb E[d_i] + \mathrm{tr}\,\mathrm{Cov}(r_i,d_i)$。
対角 $C_{ii}$ は「期待勾配の内積」ではなく、この共分散込みの量である。交差対にはこの問題が無い。
提案は対角と非対角を同じ制約に並べているが、推定量としての意味が違う。

### 4.4 $P=I$ は選択ではなく制約だった

理論文書 §4.9.2: 測定した checkpoint（`klw_control_step300_hf`）は 3 GPU 保存の FSDP を HF にマージしたもので、
`exp_avg_sq` が無い。Adam が実際に適用するのは $g/(\sqrt v+\epsilon)$ で、前処理係数は 1 ユニット内で 45〜2000 倍動く
（§4.7.2）。$r^\top P d$ の符号は $r^\top d$ と一致するとは限らず、§4.15.5 が言うとおり $\cos(Pg_i,Pg_j)$ の分子は
$g_i^\top P^2 g_j$ であって交差効果 $g_i^\top P g_j$ ですらない。

本ホストにある Adam 状態付き・world size 2 の OPD+GRPO checkpoint は
`~/checkpoints/verl_agent_opd_grpo_tmp_multitask/global_step_*`（8/13 signweight target アーム、`optim_world_size_2_rank_{0,1}.pt`
各 6.9 GB）だけである。8/5 control は world size 3 で、プローブは 2 GPU では読めない。
**Adam 幾何の $C$ は測れるが、control では測れない。**

### 4.5 測定点が 1 つ、しかも OPD が効かなくなった後

$C$ は step 300 の 1 点。理論文書 §4.3 は、このアームでは 200 step 以降に全指標が control と一致することを示している。
つまり $C$ を測ったのは、OPD が到達点に寄与しなくなった後の点である。そこで「OPD が RL 損失を押し戻している」と出るのは
§4.1 の命題どおりで、係数を決める情報ではなく「正則化が効いている」という確認にすぎない。

早期（step ≤ 60）の $C$ は測られていない。E−1 の在庫（8/13 アームの `global_step_{25,…,300}`、world size 2、Adam 状態付き）で
測ることはできるが、上記のとおり control ではない。

## 5. 測定に残る信号: webshop-OPD 列

webshop-OPD 列は 3 行とも負で、負のバッチ数は 7/8、5/8、5/8、$t$ は −2.8 / −2.5 / −1.75。単独では最も強い構造で、
理論文書の 2 つの独立な観測と向きが一致する:

* §4.14.3: search↔webshop の OPD どうしが 8/8 で負（中央値 −0.12）。
* §3.6: 出力空間で 2 run とも符号が再現する唯一のペアが alfworld ← webshop で、両方とも負（−0.055 / −0.056）。

3 つの測定（OPD–OPD 幾何、RL–OPD 交差効果、出力空間の報酬予測）が「webshop 教師の押す方向は他タスクの報酬と食い違う」
を指している。ただし本測定単独では Bonferroni 後に非有意で、checkpoint も 1 点である。

これは QP の入力ではなく**診断**として読むべきである。もし係数に反映させるなら、測定に支持されている自由度は
$b_{\text{web}}$ の 1 つで、値は統計量の選択で 0.005〜0.39 を動く（§3.2）。「$b_{\text{web}}\in\{1, 0.5, 0\}$ の 3 水準」
のような設計の方が、QP の解を 1 つ固定するより測定に忠実である。

## 6. 緩和版への所見（提案が未設計とする部分）

計算した緩和と解:

| 緩和 | $b^*$ | 所見 |
|---|---|---|
| 和制約 $(\mathbf 1^\top C)\,b\ge 0$ のみ | (0.90, 1, 0.21) | §4.1 の命題により停留点で必ず発火。E1 と同じ |
| hinge 罰則 $\mu\sum_i\max(0,-C_ib)$ | $\mu=1$: (0.87, 0.96, 0.37) → $\mu=30$: (0, 0, 0) | $\mu$ に単調で、$\mu$ を決める原理が無い |
| $\lvert t\rvert>2$ の成分だけ残す | (1, 1, 0) | 多重比較を無視している。かつ webshop 全停止 |
| 「現行より悪化させない」$C_ib\ge C_i\mathbf 1$ | $b=\mathbf 1$ | 自明。何も決めない |

どの緩和も、含んでいる情報は「webshop の OPD を下げる」以上ではなく、値は緩和の選択で決まる。
**緩和で消えないのは §4.1 の構造で、$\sum C<0$ は雑音ではなく正則化の性質である。** 緩和の設計を続けるより、
一次の RL 損失を基準に OPD 量を決める枠組み自体が OPD の価値を見ない（§4.2）ことを受け入れる方が整合的である。

整合的な使い方は 2 つ:

* $C$ を診断に使い、係数は 3 アームの成功率で決める（提案の実験設計はそのまま使える。$b$ の値だけ QP に委ねない）。
* 先に E1（$\beta(t)$ 減衰、cross-task 情報なし）を走らせ、それでも残る差があるときに初めてタスク別の配分を問う。
  §4.1 により、QP が出す「減衰」の大部分は E1 が既に持っている。

---

## 7. 実験設計への所見

* 3 アーム（固定 / 同じ平均係数の一律減衰 / タスク別）は正しい対照である。ただし事前予測は「@300 以降の短区間なら
  3 アームとも区別できない」（§4.2）。差が出うるのは search と webshop で、search は負の側。
* 検出力: alfworld の反復 SD 1.39pp（$n=3$、$\sigma$ の 95% CI は $[0.5\hat\sigma, 6.3\hat\sigma]$）。同一 checkpoint の検証 3 回、
  `RUN_TAG` を変えないと per-instance dump が上書きされる（理論文書 §6.3）。
* 早期に効かせるなら早期の $C$ が要る。step 300 の $C$ で決めた $b$ を早期に当てることは、測定点と適用点が別という意味で
  提案の前提（「測定から決めた $b$」）を満たさない。
* 「短区間固定」の区間の長さが固定点の移動量を決める。区間が短いほど alfworld / webshop は control と区別できず、
  長いほど E1 との違いが消える。

## 8. 検証できなかったこと・限界

* **Adam 幾何の $C$ は未測定。** control では原理的に測れない（§4.4）。8/13 アームで測れば $P=I$ との符号一致が分かる。
* **早期 checkpoint の $C$ は未測定。** OPD が効いている時期の交差効果は誰も見ていない。
* **$\Delta L_i^{RL}$ の実測は無い。** 理論文書 §4.14.6 と同じ留保。cosine も内積も方向の関係で、実際の Adam 更新が
  どのタスクの損失をどれだけ動かすかではない。
* **同一タスク対の共分散項は分離していない**（§4.3）。分離には同じタスクの独立 2 分割で $r_i^A$ と $d_i^B$ を組む必要がある
  （halves モードに RL 項を足せば取れる）。
* **§4.1 の命題は停留点についての主張。** step 300 は停留点ではない（control の alfworld は 150→300 で 0.651→0.754）。
  停留点でなくても $\langle\sum r,\sum d\rangle<0$ が 7/8 で観測されたことは命題と整合するが、命題の帰結ではない。
* **bootstrap は 8 バッチの再抽出で、プロンプト列は 1 本**（理論文書 §4.14.6）。シードを変えた反復ではない。
* **$b$ をタスク別にする配管は未確認。** `teacher_kl_loss_coef` はタスク共通のスカラーで、`kl_loss_coef_by_task` は
  SDAR 系トレーナーにしか無い。実装するならこの点から入るが、本文書の結論はそれを勧めない。
