## 0. 結論(先に)

1. **提案は「係数を測定で同定する目標族」である。** 既存の全アーム(klw の $\tilde W$、tilt の `exponent_scale`、curriculum の $\rho$)は
   係数を設計者が決めていた。本提案では混合係数 $w$ が教師 shift の共分散 $S$ と雑音共分散 $E$ の関数になる(§2.1)。
   **主要な介入係数は外挿 $\gamma$ 1 つ**だが、$S,E$ の推定仕様は固定が必要である。

2. **推定量は 1 本の経験 Bayes 形に統一し、和 1 の制約を外す**(§2.2)。
   S1(同タスク第 2 シード)と S2(他タスク教師)は二択ではなく、観測ベクトル $y$ に何を入れるかの違いである。
   比べるのは「単一教師」「2 シード」「2 シード + 他教師」の 3 つ。

3. **精度向上は、どの段でも第一の見込みではない。** 理由は初版の「MSE → pp の写像が無い」だけでなく、
   (a) 純 OPD 生徒は教師の分布に**着いていない**(軌跡 KL 10 nats 超、0.675 対 0.849)、
   (b) 候補等重みの MSE 改善の大半は**質量の無い裾**で起き、標本抽出される方策をほとんど変えない、
   (c) 運用 regime(GRPO+OPD、$\beta=0.01$)では目標の効き代が細いと**予想される**(上界ではない)。

4. **S3(外挿 $\gamma>1$)は同じ族の一段ではなく、別の仮説である**(§5)。
   推定モデルの中では $\gamma=1.25$ は MSE を 2.3–7.7 倍に悪化させる。効くのは $\mathrm{Cov}_{q_\gamma}(R, H) > 0$、
   すなわち教師 shift がその地点で報酬と正に対応するときだけで、これは推定問題の外にある。

5. **学習 run の前に、GPU ほぼゼロで決まることが 4 つある**(§6.1)。
   教師 3 本の標準プロトコル検証(M0)、ログからの軌跡 KL(K0)、既存ダンプからの共分散差 $\sigma_p^2$(M1′)、
   そして**合成方策の直接評価(C1)** — 命題 1 により純 OPD の到達点 = 目標なので、
   目標方策そのものの成功率が各段の(漸近的な)天井である。

6. **停止規則は限定的に書く**(§7.4)。S2 が非有意でも cross-teacher 系全体の否定にはならない。
   「この教師集合・支持・予算・実装で、事前に定めた最小有用効果を上回らなかった」と限定し、
   非有意ではなく信頼区間による同等性・無益性で判定する。

## 2. 提案手法(改訂)

### 2.1 目標族

行のタスク $d$、候補 $(x,v)$。支持は生徒 top-20 + tail(現行と同じ。**top-k + tail 上の近似目標**、§8.3)。

$$\boxed{\ \log\tilde\pi_d(v\mid x) = \log\pi_0(v\mid x) + \gamma\,\hat f_d(v\mid x) - \log Z(x)\ }$$

$\hat f_d$ は**雑音除去した shift の推定量**、$\gamma$ は**その後の外挿**。2 つを分離する。
$(\hat f_d, \gamma) = (h_d, 1)$ で control と bit 一致。

**ハイパラについて。** 主要な介入係数は $\gamma$ だけだが、$\hat f_d$ を作る統計推定の仕様
(共分散の正則化、推定用と検証用のデータ分離、質量加重の定義、role 別に分けるか)は固定しなければならない。
「ハイパラ 1 つ」ではなく「介入係数 1 つ + 固定した推定仕様」と書くのが正確である。

### 2.2 推定量 — 経験 Bayes、和の制約なし

同じ単位・同じ入力上の教師 shift ベクトル $y$ を

$$y = f + \varepsilon,\qquad \mathrm{Cov}(f) = S,\quad \mathrm{Cov}(\varepsilon) = E$$

とモデル化すると、Gaussian の下での事後平均(Gaussian でなくても最良線形予測)は

$$\hat f_d = \mu_d + S_{d,:}\,(S+E)^{-1}\,(y-\mu)$$

**係数の和は制約しない。** Bayes 解が要求する base 方向への縮小もそのまま採用する(§4.3 の理由)。
$g$ に flat prior を置けば和は自動的に 1 になり(平行移動不変)、$g\approx0$ を条件付ければ和は 1 未満になる。
どちらの解も「Bayes 最適」だが、**後者を 1 に再正規化したものは Bayes 最適ではない**。

**観測ベクトル $y$ に何を入れるかで段が決まる**:

| 段 | $y$ の中身 | 何を答えるか |
|---|---|---|
| **S0** | 既存の同タスク教師 1 本 | control(基準) |
| **S1** | 同タスク教師 2 シード | 蒸留前の目標自体が改善するか |
| **S1+X** | 同タスク 2 シード + 他タスク教師 | **cross-teacher 情報の追加価値** |

S1 と S2 を別々に走らせて優劣を比べるのではない。正しいモデルと既知パラメータの下では、
情報を増やした最適推定器は追加情報を無視する選択もできるので、最小期待 MSE は悪化しない。
問いは「S1 に他タスク教師を足す価値があるか」であり、判定は固定閾値ではなく**推定された追加利得と不確実性と計算費用**で行う。

### 2.3 S1 — 同タスク第 2 シードの幾何平均

$$\log\tilde\pi_d^{\mathrm{S1}} = \tfrac12\big(\log\pi_d^{(1)} + \log\pi_d^{(2)}\big) - \log Z$$

**生の log-probability を平均して正規化する**。これが $\sqrt{\pi^{(1)}\pi^{(2)}}$ に比例する等重み幾何平均である。
初版は「シード別 RMS で標準化してから平均」と書いていたが、それは両シードに異なる尺度を使うので等重み幾何平均にならない。
標準化の効果を見たいなら別の比較として分ける。

**性質(条件付き)。** $h^{(j)} = h^\star + b + \varepsilon_j$、$\mathrm{Var}(\varepsilon_j) = v$、$\mathrm{Corr}(\varepsilon_1,\varepsilon_2) = \rho$ とすると

$$\mathrm{MSE}\big(\tfrac12(h^{(1)}+h^{(2)})\big) = b^2 + \frac{v(1+\rho)}{2},\qquad \mathrm{MSE}(h^{(1)}) = b^2 + v$$

**半減するのは $b = 0, \rho = 0$ のときだけ。** 共通の学習データ・報酬設計・初期モデルから来る誤りは $b$ に残り、
系統的な誤りの相関は $\rho$ に残る。$\rho = 0.5$ なら比は 0.75(§10.1)。

**S1 が効くとしたら別経路もある**(R2): 幾何平均はシャープで模倣しやすい。これは MSE 論とは無関係な機構で、
C1(§6.1)で目標方策を直接評価すれば MSE 論と分離できる。

### 2.4 S1+X — ペア成分を含む非対称混合

理論 §3.1 は $s_m$ をタスク間 iid と仮定しており、その下で $w$ は一様 $(\lambda', \frac{1-\lambda'}{K-1},\dots)$ になる。
alfworld–webshop に固有のペア成分があるなら交換可能性が壊れる:

$$h_A = g + p + u_A + \varepsilon_A,\qquad h_W = g + p + u_W + \varepsilon_W,\qquad h_S = g\phantom{{}+p} + u_S + \varepsilon_S$$

(この 3 層は curriculum 設計の P7 と同じもので、理論 §3.1 がペア項を落として単純化していた。)

**モデルの含意(予測ではない)。** $g \approx 0$ で $h_S$ が目標 $p+u_A$ とも $h_A, h_W$ とも無相関なら、
2×2 解で $w_W = \sigma_p^2\sigma_\varepsilon^2/(V^2-\sigma_p^4)$、$w_S = 0$。これは**仮定の代数的な帰結**であって、
データについて反証可能なのは M1′($\sigma_p^2$ の実在)だけである。初版はこれを「強い予測」と呼んでいたが、
M1′ が出れば自動的に従う恒等式なので「モデルの含意」に改める。

なお $w_S = 0$「ちょうど」は、関連する共分散が厳密に 0 という条件の下でしか出ない。
和 1 を制約すると $w_S$ は正になる(§4.3)。

### 2.5 S3 — 外挿(別仮説、§5)

$\gamma > 1$。**推定モデルの外**にあり、同じ族の一段として扱わない。詳細は §5。

## 3. 理論: 言えること・言えないこと

### 3.1 言えること — この族が正しい形であること

* 命題 1 より、純 OPD の位置スカラー重みは $\arg\min$ を動かさない。目標を動かす以外に到達点を変える経路が無い。
  **ただしこれは漸近の言明**で、300 step の純 OPD が固定点にいるかは別問題(§3.3)。
* 教師統計を入れてよいのは目標だけ(理論 §5.1 原則 2)。本提案は $\tau$ に触らない。
* Bayes 最適な形に符号ゲート・全会一致・min・deadzone は現れない(理論 §3.3)。
* contrastive 形(共有成分の除去)は誤り。監査が同一標本で検定して悪化側(sg1 −0.042、xt1 −0.035)。

### 3.2 言えること — MSE 比 $= \lambda'$、ただし仮定したモデルの検算

交換可能モデル・flat prior・独立・不偏の下で

$$\frac{\mathrm{MSE}(\text{縮小})}{\mathrm{MSE}(h_d)} = \lambda + \frac{1-\lambda}{K} = \lambda'$$

(§10.1 で数値検証。$K=3,\lambda=0.5$ で理論値 0.667、実測 0.667–0.670。)
**これは仮定した生成モデルの検算であって、実際の RL 教師がこのモデルに従う証拠ではない。**

#### 前提の修正 (i) — 理論 §3.4 の事後分散

`cross_teacher_theory.md:237` の現行 $(\sigma_s^2+\sigma_\varepsilon^2)/K + \lambda\sigma_\varepsilon^2$ は $(1-\lambda)^2$ が抜けている:

$$\mathrm{Var}[h^\star_d \mid h] = (1-\lambda)^2\,\frac{\sigma_s^2+\sigma_\varepsilon^2}{K} + \lambda\,\sigma_\varepsilon^2$$

現行の式は $\sigma_s^2=\sigma_\varepsilon^2=1$、$K=3$ で 1.167 を与え、素の $h_d$ の 1.000 より悪い。Bayes 最適性と矛盾する。
補正後 0.667 は実測と一致。**両レビューとも解析的・数値的に確認**。§3.4 の結論(等分散なら位置に依らない)は変わらない。

### 3.3 言えないこと — MSE 改善は精度改善ではない(根拠を差し替え)

**候補等重みの MSE と、質量加重の損失は別物である。** 局所的に

$$\mathrm{KL}(p^\star\Vert\hat p) \approx \tfrac12\,\mathrm{Var}_{v\sim p^\star}[\delta(v)]$$

で、低確率候補の巨大な log-ratio は実際の分布への影響が小さい。一方、成功率には少数の行動選択・引数・終了判断が強く効く。
**平均 MSE が下がっても、重要な候補の順位が逆転して成功率が下がることは十分ありうる。**

repo の実測がこれを裏づける(handover §3.2): 1 位置あたり教師が $p\approx0.75$ を置く候補が 1 個あり、それは base から
0.1 nats 以内(`neutral_on_task_silent`、教師質量の 64.7%)。**教師の RL は頭を動かしていない。**
$h$ の分散は残り 18 個の $p\sim10^{-3}$ 以下の候補が支配する。S1 が半分にする分散の大半は、標本抽出に影響しない場所で起きる。

**初版が挙げた反例(signweight target アーム @300 で control と一致)は regime を取り違えていた。**
そのアームは GRPO+OPD、$\beta=0.01$ で、理論 §4.5 が「$A\ne0$ では報酬が単独で固定点を決める」と予測する regime。
一致は予測どおりで、写像欠如の証拠ではない。純 OPD での証拠は **position アーム**(@300 で 0.714 対 control 0.675、各 1 回、
1 対 1 の SE ≈ 1.96pp)で、こちらは逆に「命題 1 により固定点が同じでも精度が違う」= **300 step の純 OPD は固定点にいない**を示す。
単一 draw なので断定はしないが、「純 OPD には目標を動かす以外の余地が無い」は漸近の言明であって 300 step には当たらない。

### 3.4 前提の修正 (ii) — 「GRPO 下では上界」を撤回

初版 §3.5 は「$\lambda'$ の導出は報酬を含まない二乗誤差問題なので、GRPO 下では利得の上界」と書いた。**これは誤りである。**

反例(R1)。2 行動、固定点 $\pi^\star(a)\propto q(a)\exp(Q(a)/\tau)$ で、正解行動の教師確率を 0.01 → 0.02 に改善し、
報酬項が正解のオッズを 50 倍にすると

$$0.01 \to 0.3356,\qquad 0.02 \to 0.5051$$

純模倣なら +1pp、報酬を加えた固定点では **+16.95pp**。**報酬は教師の改善を増幅しうる。**
これは SDAR の効果予測ではなく、「上界」という一般命題への反例である。

**残る妥当な仮説**: $\beta=0.01$、$|\tilde Q|\sim1$ で固定点は $\pi_d\exp(100\tilde Q/W)$、目標が固定点を決めるのは
$A=0$ の位置と初期動学に限られる(理論 §4.5)ので、目標改善の効き代は**細いと予想される**。
ただし補完(増幅)も競合(打ち消し)もありうるので、**向きは実験で決める**(§6.2 の順序 5)。
理論 §3.3 への但し書きは「報酬を含まない問題設定である」までに留め、「上界」とは書かない。

### 3.5 位置依存 $\lambda(x)$ は第 2 シードから、教師と独立に出る(R2)

理論 §3.4 自身が「異分散なら $\tau(x)\propto1/\sigma_\varepsilon^2(x)$」と書いている。第 2 シードがあれば
$(h^{(1)}-h^{(2)})^2$ を role / $p$ 帯で pool して $\sigma_\varepsilon^2(x)$ が推定でき、**教師と独立な信号から**位置依存の
$\lambda(x)$ が出る(原則 2 に反しない)。一様 $\lambda$ は裾の雑音を頭にも適用する。効くとすれば位置依存版であって一様版ではない。
設計変更なので本提案の第 1 run には入れないが、**M2 は最初から role / $p$ 帯別に記録する**(§4.2)。

## 4. 係数の同定

### 4.1 M1′ — $\sigma_p^2$ は符号ではなく共分散差から

4 層モデルの 2 次モーメント:

$$\mathrm{Cov}(\hat h_A,\hat h_W) = \sigma_g^2+\sigma_p^2,\qquad \mathrm{Cov}(\hat h_A,\hat h_S) = \mathrm{Cov}(\hat h_W,\hat h_S) = \sigma_g^2$$

したがって **$\sigma_p^2 = \mathrm{Cov}(\hat h_A,\hat h_W) - \mathrm{Cov}(\hat h_A,\hat h_S)$** が既存ダンプ
(監査は候補ごとの $\delta_{on},\delta_{src},\delta_{base}$ を持つ)から**走行ゼロ**で出る。
$\mathrm{Cov}(A,S) = \mathrm{Cov}(W,S)$ はモデルの検定可能な制約でもある。
**質量加重・role 別・alfworld 行で、同じ状態・同じ候補集合の上で**取る。

初版の M1(中心化した符号一致 $\phi$、§8.1 のカウンタ 3 つ)は監査 §10-4 の未解決を片付けるには十分だが、
**符号相関は連続値の共分散ではない**。符号が一致する標本で振幅が大きく不一致で小さければ、一致率 50% でも正の共分散を持ちうる。
逆に正の符号相関があっても、共有知識か共通の誤りかは分からない。$\phi$ は補助診断に降格する。

初版 §6.2 の「chance 補正後に一致が消える → ペア分散なし / 残る → $w_S=0, w_W>0$ が確立」は強すぎる。
M1′ が出て初めて S1+X の係数が計算できる。

### 4.2 M2 — 「共通入力上のシード間変動」、質量加重・role 別

$$\tfrac12\,\mathrm{Var}\big(h_d^{(1)} - h_d^{(2)}\big) = v(1-\rho)$$

**これは共通バイアス $b$ を含まず、シード相関 $\rho$ を割り引いた量である。** 初版の「教師の推定誤差 $\sigma_\varepsilon^2$ の直接同定」は
言い過ぎで、正しくは「シードで変わる部分」の推定。シードで変わらない誤りは定義上 $s_d$(知識)に数えられる。
これは S1 の妥当性を壊さないが、「$\varepsilon_d$ は成功に寄与しない」を「シード固有の揺らぎは成功に寄与しない」に弱める。

**定義は質量加重で**: $\sum_v p(v)(h^{(1)}_v - h^{(2)}_v)^2$($p$ は $\pi_d$ か生徒質量)、
またはより直接に $\mathrm{KL}(\pi_d^{(1)}\Vert\pi_d^{(2)})$。role / $p$ 帯ごとに出す(§3.5)。
初版の V3($\mathrm{KL}(\pi^{(1)}\Vert\pi^{(2)}) > 0$)はこの向きの検査になっていたが M2 はなっていなかった。

**等分散仮定について。** alfworld の第 2 シードだけから webshop / search の $E$ を決めるには、教師間の等分散仮定が要る。
search は教師学習の KL 係数が 10 倍違う(0.001 対 0.01、`abs_delta_mean` 7.29 / 5.42 / 1.98 nats)ので、
「タスク差は二次」として省略する根拠は無い。D2 で alfworld のみと決めるなら、$E$ の他タスク成分は**仮定として明記**する。

### 4.3 和 1 の再正規化は Bayes 解を壊す(初版 §4.4 第 2 表の撤回)

初版 §4.4 の同じモデル($\sigma_g^2 = 0$、$\sigma_p^2=\sigma_u^2=\sigma_\varepsilon^2 = 1$)で、alfworld の目標に対する係数と MSE(§10.2 で再計算):

| 推定法 | $(w_A, w_W, w_S)$ | 係数和 | MSE |
|---|---:|---:|---:|
| 制約なし Bayes 線形解 | $(0.625, 0.125, 0)$ | 0.75 | **0.6250** |
| 初版の「和 1 に再正規化」 | $(0.8333, 0.1667, 0)$ | 1 | **0.7778**(+24%) |
| 最初から和 1 を制約して最適化 | $(0.6875, 0.1875, 0.1250)$ | 1 | **0.6875** |

**再正規化は Bayes 解より MSE を約 24% 増やす。** さらに、和 1 を要求すると**内容位置でも search の最適係数が正になる**。
「Bayes 最適」「係数和 1」「search は厳密に 0」を同時に一般的な性質として主張できない。

**採用**: 係数和 1 を外す(§2.2)。Bayes 解が求める base 方向への縮小もそのまま採用する。
$g\approx0$ を信じるなら Bayes 解は「base へ向けても縮む」ことを言っており、これは curriculum アームの
「base と on-task の間に目標を置く」制限と同じ形である。初版の V2($\sum w = 1$)は撤回する。

交換可能モデル・$T=1$・200k 標本(§10.1):

## 5. S3(外挿)— 別仮説として

### 5.1 初版の前提「生徒は教師に着いている」は偽である(R2)

初版 §5.1 は `teacher_kl` 0.571 → 0.005 nats と on_travel 0.99 から「目標を動かす以外に上がる道が無い」と結論した。
この量には 4 つの但し書きがある(R1、handover §12.3):

* 引用値は**書き換え後の目標 $\tilde p$ への KL** である。
* 生徒 top-20 + tail に集約した KL なので、**tail 内部の相違を捉えない**。
* **訪問状態上のトークン平均**なので、重要な少数状態の誤差を隠す。
* $1 - 0.005/0.571$ は KL の**相対減少率**で、方策空間を 99% 移動したという距離ではない。

そして軌跡分布の KL は連鎖律で $\sum_t\mathbb E[\mathrm{KL}_t]$ = 応答長 × トークン平均:

| 量 | 値 | 出典 |
|---|---:|---|
| `teacher_kl`(alfworld、step150、トークン平均) | 0.004–0.005 nats | handover §4 |
| `episode/response_tokens/mean`(1 エピソード) | ≈ 2,750 | handover §7(`:458`) |
| **軌跡単位の KL(下界)** | **≈ 10 nats 超** | 積。top-20+tail への粗視化は KL を下げるので下界 |
| 純 OPD control alfworld @150 → @300 | 0.651 → **0.675** | 理論 §4.2(`:321`) |
| 純 OPD position @150 → @300 | 0.690 → **0.714** | 同上(各 1 回) |
| GRPO+OPD control @300 | 0.754 | 理論 §4.2 |
| **単タスク参照(SDAR@300 alfworld)** | **0.849** | pg_weight_design §0.4(`:57`) |

**教師 checkpoint 自身をこのホストの標準プロトコルで検証した記録は無い。** 0.849 が `teachers/alfworld_step300` の値か、
同じ 1.7B か、同じプロトコルかは M0(§6.1)で確定させる。**それでも**軌跡 KL 10 nats 超はログだけから出る事実で、
「生徒は教師の分布に着いている」は成功率を決める粒度では成立していない。

帰結: **S3 の動機「教師が天井で、生徒は天井に着いた」は消える。** 生徒はまだ教師の手前にいる。
目標を教師の 1.25 倍先へ置いても、律速は現在の目標への到達である。S1 / S1+X の利得も、17pp 規模の模倣不足の前では二次である。

### 5.2 S3 が効く条件 — $\mathrm{Cov}_{q_\gamma}(R, H) > 0$(R1)

固定状態で $q_\gamma(a)\propto\pi_0(a)e^{\gamma H(a)}$ と置くと

$$\frac{d}{d\gamma}\,\mathbb E_{q_\gamma}[R] = \mathrm{Cov}_{q_\gamma}(R, H)$$

**外挿が効くのは、教師 shift $H$ がその地点で報酬と正に対応しているときだけ。** 誤った行動や過長な応答に高い shift が付いていれば、それも増幅する。
これは推定問題(「$h^\star_d$ を推定する」)の外の条件で、§4.4 の S3 列(推定モデル内では有害)と矛盾しない。
同じ文書に「$h^\star_d$ = 雑音込みの推定の真値」と「$h^\star_d$ = 踏み込み不足の方向の先」という 2 つの読みが同居していたのが初版の問題で、
本改訂では S3 を**ExOPD のモデルに基づく別仮説**として分離する。

### 5.3 走らせる条件

* **C1(§6.1)で外挿方策 $\pi_0(\pi_d/\pi_0)^{1.25}$ の成功率を直接測ってから。** 学習 run は要らない。
  $\pi_d$ を上回るなら S3 の仮説が生き、下回るなら §5.2 の $\mathrm{Cov}(R,H)$ が負であることの直接の証拠になる。
* 純 OPD 生徒が教師の成功率に届いた後(§5.1)。
* $\gamma \in \{1, 1.25\}$ の 2 水準。1.25 は ExOPD からの初期候補で、本タスクでの最適値の根拠ではない。
  ExOPD 自身が 1.5 で不安定化を報告している(R1 確認)ので、上方探索は別 run に分ける。
* search は前提(教師への到達)がさらに遠い(`teacher_kl` 0.025、他の 4–6 倍)ので初期実験から外す。**予算上の判断**であって、理論上 S3 が成立しないとは言えない。

### 5.4 「S3 だけが教師を超えうる」の撤回

S1 のアンサンブル(2 シードの幾何平均)や S1+X の推定改善によって、個々の教師を超えることは可能である。
教師を完全模倣した場合の等価性(命題 1)は、任意の学習結果やアンサンブルの成功率に対する上限ではない。
初版 §7.2 の「唯一、教師を超えうる段」は撤回する。

| 段 | 予測 | 根拠 |
|---|---|---|
| **C1**(S3 目標の直接評価) | $\pi_0(\pi_d/\pi_0)^{1.25}$ は $\pi_d$ を**下回る**可能性が高い | §5.2 の $\mathrm{Cov}(R,H)$ は書式・長さの shift で負に振れやすい。ExOPD の +2.0pt は別設定 |

| **S3**(純 OPD) | C1 が正のときのみ走らせる。その場合 alfworld @300 で control 以上 | §5.3 |

### 7.3 反証条件(修正)

| 段 | 反証条件 | 意味 |
|---|---|---|
| S1 | **目標方策(C1)が $\pi_d$ より 2 SE 以上下** | 幾何平均が模倣しやすいという仮説と MSE 論の両方が否定される |
| S1 | 生徒が control より 2 SE 以上下、**かつ**質量加重 shift 誤差(V3)は改善 | **MSE モデルが正しくても成功率は悪化しうる**(§3.3)。初版の「モデルか配線が誤り」は不適切。重要候補の順位逆転を role 別に調べる |
| S1+X | S1 との差が負で 2 SE 超 | 混入がバイアス(§9)。M1′ の $\mathrm{Cov}(A,S)\ne\mathrm{Cov}(W,S)$ なら 4 層モデル自体が誤り |
| S3 | C1 で外挿方策が $\pi_d$ を下回る | $\mathrm{Cov}(R,H) < 0$。走らせない |
| S3 | 走らせて webshop が 2 SE 以上下、または clamp 発火率 > 5%、または応答長 +20% 超 | 外挿が裾・長さを壊している(ExOPD の 1.5 と同じ症状) |

**各段の反証は独立である。** S1 の失敗は S3(別仮説)を否定しない。

### 7.4 停止規則(限定的に)

初版は「S2 が null なら cross-teacher 系全体を畳める」と書いた。**これは強すぎる。**
線形 Gaussian モデルでの MSE 最適性は、異分散・多峰性・タスク成功率に対する非線形ゲートの優劣を決めない。

停止規則は次のように限定する:

> **この教師集合・この支持(生徒 top-20 + tail)・この予算(300 step)・この実装で、S1+X は S1 に対して
> 事前に定めた最小有用効果(alfworld 3.9pp、webshop acc 1.3pp)を上回らなかった。**

判定は非有意ではなく、**信頼区間による同等性・無益性**で行う(差の 95% CI が最小有用効果を含まないこと)。
評価は最終成功率に加えて、サブタスク別の増減、学習曲線、応答長、打ち切り率、教師追加学習を含む**総計算量**で行う。

## 8. 実装

### 8.1 M1′ — 共分散差(主)と符号 $\phi$(補助)

**主**: `scripts/cross_teacher_offline_audit.py` の経路で、候補ごとの $(\delta_{on},\delta_{src},\delta_{base})$ から
base 統制後の $\hat h$ を作り、$\mathrm{Cov}(\hat h_A,\hat h_W)$、$\mathrm{Cov}(\hat h_A,\hat h_S)$、$\mathrm{Cov}(\hat h_W,\hat h_S)$ を
質量加重・role 別に出す。同じ状態・同じ候補集合・同じ重みの下で。

**補助**: `sign_weights.py` の `pair_both` / `pair_same`(`:444-445`、`:542-543`、`:696`)と同じ分母 `both` の上でカウンタ 3 つ
(`pair_on_pos`、`pair_off_pos`、`pair_both_pos`)を足し、`agree_chance` / `agree_phi` / `agree_excess` を `agree_rate` の隣に出す。
比の平均は比ではないので**カウンタを出して比は後で作る**。母集団(生徒 top-20 / $\epsilon=0.1$ nats)は監査 §4.1 の $\phi$ と違うので直接比較しない。

### 8.2 S1+X — 線形和の直接経路(`pair_source` 流用の撤回)

初版 §8.3 は `nested_layers` の `pair_source` を流用して S2 を書けるとしたが、**線形混合にならない**。
`nested_layers`(`cross_teacher_target.py:481-508`)は

```python
agrees = (hat_off.sign() == sign.unsqueeze(-1)) & (sign.unsqueeze(-1) != 0)   # 符号ゲート
capped = torch.where(agrees, torch.minimum(o.unsqueeze(-1), off_nats), 0)     # min で振幅制限
pair_mag, pair_src = capped.max(dim=-1)                                        # max で教師選択
```

の 3 つの非線形を持ち、$\rho_{pair}$ を教師別にしてもこれらは残る。
S1+X には、標準化した shift $\hat h_m$ から **係数付き線形和 $\sum_m w_m\hat h_m$ を直接作る経路**が要る。
`build_target` の $c$ を

$$c = \gamma\,\hat f_d - h_d,\qquad \hat f_d = \sigma_d\sum_m w_m\hat h_m\ (+\text{base 縮小項})$$

に差し替える。$w$ は run 開始前に M1′ / M2 から計算して config に固定する(推定仕様の固定、§2.1)。

### 8.3 tail — 現行は tilt されない。近似目標であることを明記

`normalized_weight`(`:694`)の docstring: "THE TAIL IS IN Z AND IS NOT TILTED"。現行は

$$Z = \sum_{v\in S}p_{on}(v)e^{c(v)} + p_{on}(\mathrm{tail})$$

設計書どおり tail にも混合 shift $c_{\mathrm{tail}}$(`tail_on` / `tail_off` から)を適用するなら

$$Z = \sum_{v\in S}p_{on}(v)e^{c(v)} + p_{on}(\mathrm{tail})\,e^{c_{\mathrm{tail}}}$$

への変更が要る。**ただしそれでも「tail を 1 カテゴリとして幾何混合」と「全語彙で幾何混合してから tail を集約」は一般に一致しない。**
本提案の目標は **top-k + tail 上の近似**であることを明記し、V7 で少数サンプルの全語彙計算との差を報告する。

### 8.4 S1 — 教師キャッシュの鍵衝突と恒常コスト

`teacher_cache.py` は task 名で引かれている(`self._weights[task]`、`(n_tasks * vocab, hidden)` の stacked projection)。
同じ task の第 2 シードは素直に足すと鍵が衝突する。選択肢:
(a) 別の task 鍵(例 `alfworld@seed2`)を与え、routing に「同じタスクの教師」と教える(`off_plane_tasks` の 1 対 1 前提の修正)。
(b) 鍵を (task, seed) にする。D2 で alfworld のみなら (a) が安い。

**恒常コスト(R2)**: `sign_weight_forward` が 1 step の **21%(143 s)** を占める
(speedup_proposal `:168`)。平面が 1 本増えると概算で **1 割弱遅くなる**。初版の「コスト: 教師 1 本の学習 run」はこれを含んでいなかった。
prefetch 経路や cache の実装で変わる概算。

### 8.5 C1 — 合成 sampler

vLLM では複数モデルの logit 合成が難しい。`rollout.name=hf` の経路は存在する(`fsdp_workers.py:518`)が、
複数モデルの logit を合成して標本抽出する配線は無い。**読みだけで書いており、試していない。**
C1′(重み平均 safetensors)はコード変更ゼロの代理だが、PoE とは別物。

## 9. 限界(正直な見通し)

* **本提案に新しい測定は無い。** §3・§4 は解析とモンテカルロ、§5・§6 は既存文書からの再読。M1′・M2 はどちらも未測定。
* **教師の成功率は未測定**のまま論じている。0.849 が 1.7B 教師の値でなければ §5.1 の 17pp は変わるが、軌跡 KL と純 OPD 0.675 は変わらない。M0 で確定させる。
* §3.3 の position アームの +3.9pp は各 1 回の検証で 2σ 程度。単独では主張にならない。
* **§4.4 の合成推定量は flat prior・等分散・独立・不偏の下の計算**で、仮定への批判(§2.3 の $b$、$\rho$)は合成推定量にも同じだけ当たる。
* **4 層モデル(g / p / u / ε、ガウス、iid)は仮定。** off-task 教師が task d の内容位置で相関した誤りを持つなら、混入はバイアスで MSE は上がりうる。klw 系が webshop を一貫して悪化させた実績(理論 §4.6)がその向きの状況証拠。
* **等分散仮定**(§4.2)。alfworld の $E$ を search に流用する根拠は無い。
* **効果量は小さいと予測される。** 写像の欠如に加え、$\lambda\to1$ で削減率は 0 に収束。2 シード・中間 checkpoint・AUC で読む設計が要る。
* **Open-MOPD の対立仮説を潰していない。** 予算配分(長さ差・drift・staleness)が原因なら本提案の効果はそれに埋もれる。headroom 回収 35.6% → 83.4% は本提案が期待する効果量より 1 桁大きい。独立に確認する価値がある。
* **Wu+ 2026**: Merge / Mix-RL / MOPD がドメイン平均 1.4pt しか違わない。「教師の混ぜ方」という軸自体が薄いという外部証拠。
* `_EXPONENT_CLAMP` の発火率、追加平面の実コスト、C1 の実装要件は未測定・未試行。

### 10.1 §4.4 の表(S1 / S2 / S1+X / S3 / $\rho$、§3.2 の修正)

```python
import random, math
def solve3(M, c):
    A = [row[:] + [c[i]] for i, row in enumerate(M)]
    for i in range(3):
        piv = max(range(i,3), key=lambda r: abs(A[r][i])); A[i], A[piv] = A[piv], A[i]
        for r in range(3):
            if r == i: continue
            f = A[r][i]/A[i][i]
            for k in range(i,4): A[r][k] -= f*A[i][k]
    return [A[i][3]/A[i][i] for i in range(3)]
random.seed(0); N = 200_000; K = 3; G = 1e6
print("  lam   S2     S1     S1+X   S3(1.25)  S1(rho=.5)  doc-var  corrected  empirical")
for lam in [0.20, 0.25, 0.30, 0.50, 0.90]:
    ss, se = lam, 1-lam; sp, sq = math.sqrt(ss), math.sqrt(se); T = ss+se
    w = solve3([[G+ss+se/2, G, G], [G, G+ss+se, G], [G, G, G+ss+se]], [G+ss, G, G])  # S1+X
    a = b = c = d = s3 = rc = 0.0; rho = 0.5
    for _ in range(N):
        g = random.gauss(0,3.0); s = [random.gauss(0,sp) for _ in range(K)]
        e = [random.gauss(0,sq) for _ in range(K)]
        h = [g+s[m]+e[m] for m in range(K)]; star = g+s[0]; hbar = sum(h)/K
        shrunk = hbar + lam*(h[0]-hbar)
        e2 = random.gauss(0,sq); seed2 = g+s[0]+(e[0]+e2)/2
        comp = sum(w[i]*y for i, y in enumerate([seed2, h[1], h[2]]))
        e2c = rho*e[0] + math.sqrt(1-rho*rho)*random.gauss(0,sq); seed2c = g+s[0]+(e[0]+e2c)/2
        a += (h[0]-star)**2; b += (shrunk-star)**2; c += (seed2-star)**2
        d += (comp-star)**2; s3 += (1.25*h[0]-star)**2; rc += (seed2c-star)**2
    lamp = (1+(K-1)*lam)/K
    print(f"  {lam:.2f}  {b/a:.3f}  {c/a:.3f}  {d/a:.3f}   {s3/a:.3f}     {rc/a:.3f}"
          f"     {T/K+lam*se:.3f}    {(1-lam)**2*T/K+lam*se:.3f}      {b/N:.3f}")
```

### 10.2 §4.3 の表(再正規化が Bayes 解を壊すこと)

```python
gg, pp, uu, ee = 0.0, 1.0, 1.0, 1.0
V, VS = gg+pp+uu+ee, gg+uu+ee
Sig = [[V, gg+pp, gg], [gg+pp, V, gg], [gg, gg, VS]]
cov = [gg+pp+uu, gg+pp, gg]; varT = gg+pp+uu
def mse(w): return varT - 2*sum(w[i]*cov[i] for i in range(3)) + sum(w[i]*Sig[i][j]*w[j] for i in range(3) for j in range(3))
w_bayes = solve3(Sig, cov)                       # (0.625, 0.125, 0.000)  MSE 0.6250
w_renorm = [x/sum(w_bayes) for x in w_bayes]     # (0.833, 0.167, 0.000)  MSE 0.7778  <- 初版の第 2 表
# 和 1 を最初から制約(Lagrange): [Sig 1; 1' 0][w; mu] = [cov; 1]
def solve4(M, c):
    A = [row[:] + [c[i]] for i, row in enumerate(M)]
    for i in range(4):
        piv = max(range(i,4), key=lambda r: abs(A[r][i])); A[i], A[piv] = A[piv], A[i]
        for r in range(4):
            if r == i: continue
            f = A[r][i]/A[i][i]
            for k in range(i,5): A[r][k] -= f*A[i][k]
    return [A[i][4]/A[i][i] for i in range(4)]
w_con = solve4([Sig[0]+[1], Sig[1]+[1], Sig[2]+[1], [1,1,1,0]], cov+[1])[:3]   # (0.6875, 0.1875, 0.125)  MSE 0.6875
for name, w in [("Bayes", w_bayes), ("renorm", w_renorm), ("sum-1 opt", w_con)]:
    print(f"{name:10s} w=({w[0]:.4f},{w[1]:.4f},{w[2]:.4f}) sum={sum(w):.3f} MSE={mse(w):.4f}")
```
